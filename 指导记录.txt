指导记录

本次指导围绕 MCPFlow 多智能体编排平台的基建框架展开讨论。项目采用 Go+Gin+MongoDB 技术栈，实现了 DAG 工作流引擎，支持 LLM、Agent、Condition 等八种节点类型及 MCP 协议的 Streamable HTTP/SSE 双模连接。指导教师肯定了整体分层架构（config→store→engine→api）的清晰性，同时提出优化建议：一是补充配置热加载与密码脱敏机制，避免 API Key 明文落库；二是 Agent 节点引入连接池复用 MCP 客户端，降低频繁建连开销；三是工作流执行增加超时控制与断点重试能力，提升生产环境鲁棒性。后续将按上述方向持续完善。

本次指导围绕毕业论文答辩 PPT 及配套文档的编写展开。指导教师审阅了 PPT 初稿后指出：一是技术架构页需用分层架构图直观展示 Go 后端→DAG 引擎→MongoDB 的调用链路，替代纯文字罗列；二是核心创新点（MCP 协议双模连接、Agent 工具动态发现）应在 PPT 前三分之一处单独呈现，强化评审记忆点；三是实验结果页需补充与 LangChain/AutoGen 的横向对比数据，量化多智能体编排效率提升。关于论文正文，建议在系统设计章节增加关键节点（Agent 节点、条件分支）的执行流程图，并在测试章节补充异常场景（MCP 服务断连、工具调用超时）的容错验证记录。
